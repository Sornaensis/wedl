schema direction. It is withdrawn and superseded by
[ADR 0002](../architecture/adrai/decisions/R01M/R01M48NHJBX1HWE7RG8G2S3DD9H--shared-world-concurrent-narrative-threads.decision.md).

ADR 0002; any future thread representation requires the separately approved
follow-up B.

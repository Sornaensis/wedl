# Small examples

[Chronology requests](chronology-api-v1.yaml) show formatting, conversion,
annotation search and story-time lookup. Each named mapping is a complete
request: write the chosen mapping as JSON in a request file and replace the calendar ID
with one from your world's catalogue. Read the [chronology guide](../guides/chronology.md)
for commands and the meaning of the results.

[Object affordances](object-affordances-v07.yaml) illustrates authored object
fields, including explicit empty values and absent fields. It is a collection
of record fragments, not a world you can load. See the [manual](../README.md)
for authoring records.

For a runnable world, start with the [Tideglass walkthrough](../stories/tideglass/walkthrough.md)
and its [query and edit recipes](../stories/tideglass/queries.md).
